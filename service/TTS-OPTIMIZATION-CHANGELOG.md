# TTS 优化功能更新日志

## 版本 1.1 - 2025-10-08

### 🔄 重要变更

**情绪识别逻辑调整**：从完整文本（包括括号内容）识别情绪，而不是只从括号内容识别。

### 📝 详细说明

#### 变更前（版本 1.0）
```typescript
// 优先从括号内容识别情绪
if (psychologicalDesc) {
  detectedEmotion = this.detectEmotionFromText(psychologicalDesc);
}
if (!detectedEmotion && emotion) {
  detectedEmotion = emotion;
}
if (!detectedEmotion) {
  detectedEmotion = this.detectEmotionFromText(textToSpeak);
}
```

**问题**：只从括号内容识别情绪，可能遗漏对话文本中的情绪信息。

#### 变更后（版本 1.1）
```typescript
// 从完整文本（包括括号内容）识别情绪
if (emotion) {
  detectedEmotion = emotion;
}
if (!detectedEmotion) {
  detectedEmotion = this.detectEmotionFromText(prompt); // 使用完整文本
}
```

**优势**：综合考虑括号内容和对话文本，情绪识别更准确。
