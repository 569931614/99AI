# TTS 优化功能快速指南

## 🚀 快速开始

### 1. 重启服务

```bash
cd service
pnpm dev
```

### 2. 测试功能

在聊天界面发送包含括号的消息，点击朗读按钮：

```
输入: "你好啊！（内心充满喜悦）今天天气真不错呢~"
```

**预期效果**:
- ✅ 只朗读: "你好啊！今天天气真不错呢~"
- ✅ 使用开心音色（如果配置了情绪映射）

## 📋 功能说明

### 括号过滤

**支持的括号类型**:
- `()` 英文圆括号
- `（）` 中文圆括号
- `[]` 英文方括号
- `【】` 中文方括号
- `{}` 英文花括号
- `「」` 日文引号
- `『』` 日文双引号

**示例**:
```
输入: "我明白了【点头】，那我们开始吧！"
朗读: "我明白了，那我们开始吧！"
```

### 智能情绪识别

**识别优先级**:
1. 使用API参数 `emotion`
2. 从完整文本（包括括号内容）识别情绪

**示例**:
```
输入: "没关系的...（内心非常生气）我不在意。"
识别: angry（从完整文本识别，包括"内心非常生气"）
音色: 生气音色
朗读: "没关系的...我不在意。"
```

## 🎯 支持的情绪

|------|-----------|

| angry | 生气、愤怒、恼火 |
| gentle | 温柔、柔和、亲切 |

| calm | 平静、冷静、中性 |

## ⚙️ 配置情绪映射

### 全局配置

在管理后台配置全局情绪→音色映射：

```json
{
  "happy": "voice-id-for-happy",
  "sad": "voice-id-for-sad",
  "angry": "voice-id-for-angry"
}
```

配置键: `emotionVoiceMap:global`

### 应用配置

为特定应用配置情绪→音色映射：

```json
{
  "happy": "app-specific-happy-voice",
  "sad": "app-specific-sad-voice"
}
```

配置键: `emotionVoiceMap:app:{appId}`

启动服务后，TTS处理会输出详细日志：

```
[TTSService] 开始TTS处理: 你好啊！（内心充满喜悦）...
[TTSService] 提取心理描述: 内心充满喜悦
[TTSService] 移除括号后的文本: 你好啊！今天天气真不错呢~
[TTSService] 从完整文本推断情绪: happy (文本: 你好啊！（内心充满喜悦）...)
[TTSService] 命中情绪映射: emotion=happy, voice=xxx (appId=123)
```

## ⚠️ 注意事项

### 1. 空文本处理

如果移除括号后文本为空，会返回错误：

```
输入: "（内心独白：我该怎么办呢？）"
结果: 400 错误 "文本内容为空，无法进行语音合成"
```

### 2. 向后兼容

如果文本中没有括号，功能与之前完全一致：

```
输入: "你好啊！今天天气真不错呢~"
结果: 正常处理，与之前行为一致
```

### 3. 情绪映射回退

如果未配置情绪映射，会按以下顺序回退：
1. 应用默认音色
2. 全局默认音色
3. 系统默认音色

## 🔧 故障排查

### 问题1: 括号内容仍被朗读

**检查**:
- 确认服务已重启
- 检查日志是否显示"移除括号后的文本"
- 确认使用的是最新代码

### 问题2: 情绪识别不准确

**检查**:
- 查看日志中的"提取心理描述"
- 确认括号内容包含情绪关键词
- 检查情绪映射配置是否正确

### 问题3: 音色未改变

**检查**:
- 确认已配置情绪→音色映射
- 查看日志中的"命中情绪映射"
- 检查音色ID是否有效

## 💡 最佳实践

### 1. 心理描述格式

推荐使用清晰的情绪描述：

✅ 好的示例:
```
"你好！（开心地笑着）"
"我明白了【叹气】"
"真的吗？{惊讶}"
```

❌ 不推荐:
```
"你好！（做了一个复杂的动作）"  // 无法识别情绪
"我明白了【...】"  // 内容不明确
```

### 2. 情绪关键词

在心理描述中使用明确的情绪关键词：

✅ 好的示例:
```
"（内心非常生气）"
"【开心地笑着】"
"（温柔地说）"
```

❌ 不推荐:
```
"（做了某事）"  // 无情绪关键词
"【...】"  // 无法识别
```

### 3. 配置音色映射

为常用情绪配置音色映射：

```json
{
  "happy": "开心音色ID",
  "sad": "悲伤音色ID",
  "angry": "生气音色ID",
  "gentle": "温柔音色ID",
  "calm": "平静音色ID"
}
```
