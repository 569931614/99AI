# TTS 优化功能更新总结

## 📋 更新概述

**更新日期**: 2025-10-08  
**功能模块**: 文字转语音（TTS）  
**影响范围**: 后端服务 `service/src/modules/chat/chat.service.ts`

## ✨ 新增功能

### 1. 括号内容过滤
- **功能**: TTS 朗读时自动过滤括号内的心理描述
- **支持的括号**: `()`、`（）`、`[]`、`【】`、`{}`、`「」`、`『』`
- **效果**: 只朗读实际对话内容，不朗读心理描述

### 2. 智能情绪识别
- **功能**: 从完整文本（包括括号内容）识别情绪
- **识别优先级**:
  1. 使用 API 调用时传入的 `emotion` 参数
  2. 从完整文本（包括括号内容）推断情绪
- **效果**: 根据识别的情绪自动选择匹配的音色

## 🔧 代码修改

### 修改的文件

#### `service/src/modules/chat/chat.service.ts`

**新增方法**:

1. **`extractPsychologicalDescription(text: string): string | null`**
   - 提取文本中所有括号内的内容
   - 用于情绪识别
   - 支持多种括号格式

2. **`removeBracketedContent(text: string): string`**
   - 移除文本中的所有括号及其内容
   - 返回纯净的对话文本用于 TTS
   - 自动清理多余空格

**修改方法**:

3. **`ttsProcess(body, req, res)`**
   - 添加括号内容提取逻辑

   - 使用过滤后的文本进行 TTS

## 📝 使用说明

### API 调用示例

```bash
# 调用 TTS 接口
curl -X POST http://localhost:9520/api/chat/tts \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "chatId": 123,
    "prompt": "你好啊！（内心充满喜悦）今天天气真不错呢~"
  }'
```

## ⚠️ 注意事项

### 1. 向后兼容性

✅ **完全向后兼容**
- 如果文本中没有括号，功能与之前完全一致
- 不影响现有的 TTS 调用
- 不需要修改前端代码

### 2. 边界情况处理

**空文本处理**:
```
输入: "（内心独白：我该怎么办呢？）"
结果: 返回 400 错误 "文本内容为空，无法进行语音合成"
```

**无括号文本**:
```
输入: "你好啊！今天天气真不错呢~"
结果: 正常处理，与之前行为一致
```

### 3. 情绪映射配置

确保在管理后台配置了情绪→音色映射：
- 全局配置：`emotionVoiceMap:global`
- 应用配置：`emotionVoiceMap:app:{appId}`

如果未配置，会回退到应用默认音色或全局默认音色。
