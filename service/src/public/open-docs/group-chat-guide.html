📖 功能概述

什么是群聊功能？

群聊功能允许在单个对话组中添加多个 AI 角色成员，实现多角色协作对话。每个成员可以有独立的：

  • ✅ 角色预设 - 不同的性格、专业领域和对话风格
  • ✅ 任务分配 - 明确的工作目标和执行状态
  • ✅ 发言顺序 - 可控的轮流发言机制
  • ✅ 情绪音色 - 根据角色和情绪切换语音

🎯 典型应用场景

  • 产品团队协作（产品经理 + 设计师 + 开发）
  • 教育场景（老师 + 助教 + 学生）
  • 创意讨论（策划 + 文案 + 美术）
  • 客服团队（一线客服 + 技术支持）

💡 核心优势

  • 无需登录鉴权，快速集成
  • 完整的成员和任务管理
  • 支持实时和异步对话
  • 自动维护对话上下文

🚀 快速开始（5分钟上手）

前置条件：
  • 已部署 AI 服务实例（确认服务地址，如：http://your-domain:9520）
  • 已创建至少 2 个角色应用（通过 /api/open/app/createApp）
  • 准备一个唯一的 userId（任意数字，用于标识用户）

核心三步走

1

创建对话组

使用 POST /api/open/group/create 创建一个新的对话组。

POST /api/open/group/create
Content-Type: application/json

{
  "userId": 1001
}

→ 返回 groupId，后续所有操作都需要此 ID

2

批量添加 AI 成员（每人一个任务）

使用 POST /api/open/group/members/add 一次性添加多个角色，每个成员可分配一个任务。

POST /api/open/group/members/add
Content-Type: application/json

{
  "userId": 1001,
  "groupId": 123,
  "members": [
    {
      "appId": 456,
      "order": 1,
      "role": "leader",
      "taskDetail": "完成需求分析文档"
    },
    {
      "appId": 457,
      "order": 2,
      "role": "member",
      "taskDetail": "设计系统架构"
    }
  ]
}

→ 一次性添加所有成员，每个成员可选择性分配一个任务

3

开始对话

使用 POST /api/open/chat/chat-process 发起群聊对话。

POST /api/open/chat/chat-process
Content-Type: application/json

{
  "userId": 1001,
  "prompt": "我们需要设计一个新功能",
  "appId": 456,
  "options": {
    "groupId": 123
  }
}

→ AI 会根据成员顺序和任务进行协作对话

💡 提示：添加成员后会自动启用群聊模式，移除所有成员后会自动退出群聊模式。

详细步骤说明

步骤 1：创建对话组

接口：POST /api/open/group/create

参数类型必填说明
userIdnumber✅外部用户ID（任意数字）
appIdnumber❌初始关联的角色ID（可选）
modelConfigobject❌模型配置（不传则使用默认）

返回示例：

{
  "success": true,
  "data": {
    "id": 123,
    "userId": 1001,
    "title": "新对话",
    "isGroupChat": false,  // 此时还未添加成员
    "members": null,
    "createdAt": "2025-10-23T10:00:00.000Z"
  }
}

步骤 2：批量添加成员（可同时分配任务）

接口：POST /api/open/group/members/add

参数类型必填说明
userIdnumber✅外部用户ID
groupIdnumber✅对话组ID
membersarray✅成员列表（数组），一次可添加多个成员

members 数组元素：

参数类型必填说明
appIdnumber✅角色应用ID（将作为成员标识）
ordernumber✅发言顺序（数字越小越靠前）
rolestring✅成员角色（如：member、leader）
taskDetailstring❌任务描述（如："完成需求分析文档"）
💡 说明：使用 appId 作为成员标识，系统会自动从应用信息中获取角色名称。taskDetail 为可选字段，传入后会自动创建任务（状态默认为 todo）。

请求示例：

{
  "userId": 1001,
  "groupId": 123,
  "members": [
    {
      "appId": 456,
      "order": 1,
      "role": "leader",
      "taskDetail": "完成需求分析文档"
    },
    {
      "appId": 457,
      "order": 2,
      "role": "member",
      "taskDetail": "设计系统架构"
    }
  ]
}

步骤 3：发起群聊对话 重要更新

接口：POST /api/open/chat/chat-process

关键要点：

  • 必须通过 options.groupId 传递对话组ID
  • appId 参数指定当前发言的角色
  • AI 会自动按照成员的 order 顺序轮流回复
  • 任务状态会影响 AI 的回复内容
  • 重要：需要传递 isFirstMember 参数避免消息重复

群聊模式调用方式

当需要让多个角色依次发言时，需要为每个角色分别调用接口，并传递正确的参数：

参数类型必填说明
options.isFirstMemberboolean✅是否为第一个成员（仅第一个传 true）
⚠️ 重要：群聊模式下，用户发送一条消息，需要为每个 AI 角色分别调用接口。
• 第一个角色：isFirstMember: true - 会保存用户消息到数据库
• 后续角色：isFirstMember: false - 会复用已保存的用户消息
这样可以避免用户消息在对话记录中重复出现。

💡 提示：

  • 需要按成员的 order 顺序依次调用
  • 所有角色的 prompt 应该相同
  • 群聊模式下会跳过余额检查和模型限制，确保对话流畅
  • 任务会自动影响AI回复：AI会根据成员的任务描述调整回复内容和重点

步骤 4：查看成员和任务（任务持久化保存）

接口：POST /api/open/group/members/list

获取对话组的所有成员信息，包括头像、任务等。任务在添加成员时创建后，会持久化保存在对话组中，无需频繁更新。

💡 任务管理说明：
  • 任务在创建成员时通过 taskDetail 参数一次性设置
  • 任务数据持久化存储在对话组的 members 字段中
  • AI 会自动读取任务信息，调整对话内容
  • 任务设置后长期有效，无需额外维护

// 群聊功能完整示例
const BASE_URL = 'http://your-domain:9520/api/open';
const USER_ID = 1001;

// 工具函数：发送请求
async function request(endpoint, data) {
  const response = await fetch(`${BASE_URL}${endpoint}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
  });
  return response.json();
}

// 步骤1：创建对话组
async function createGroup() {
  const result = await request('/group/create', {
    userId: USER_ID
  });
  console.log('对话组已创建:', result.data);
  return result.data.id; // 返回 groupId
}

// 步骤2：批量添加成员（可同时分配任务）
async function addMembers(groupId) {
  const result = await request('/group/members/add', {
    userId: USER_ID,
    groupId: groupId,
    members: [
      {
        appId: 456,
        order: 1,
        role: 'leader',
        taskDetail: '完成需求分析文档'
      },
      {
        appId: 457,
        order: 2,
        role: 'member',
        taskDetail: '设计系统架构'
      },
      {
        appId: 458,
        order: 3,
        role: 'member',
        taskDetail: '实现核心功能'
      }
    ]
  });
  console.log(`批量添加成员成功，共添加 ${result.data.count} 个成员:`, result);
}

// 步骤3：发起群聊对话
async function startGroupChat(groupId) {
  const members = await listMembers(groupId);

  // 为每个成员依次调用接口
  for (let i = 0; i < members.length; i++) {
    const member = members[i];
    const result = await request('/chat/chat-process', {
      userId: USER_ID,
      prompt: '大家好，我们来讨论一下新功能的实现方案',
      appId: member.appId, // 当前成员的 appId
      options: {
        groupId: groupId,
        isFirstMember: i === 0     // 第一个成员为 true
      }
    });
    console.log(`成员 ${member.appName} 的回复:`, result);
  }
}

// 步骤4：查看成员列表
async function listMembers(groupId) {
  const result = await request('/group/members/list', {
    userId: USER_ID,
    groupId: groupId
  });
  console.log('成员列表:', result.data);
  return result.data;
}

// 主流程
async function main() {
  try {
    // 1. 创建对话组
    const groupId = await createGroup();

    // 2. 添加成员（同时分配任务）
    // 任务会持久化保存在对话组中，无需额外更新
    await addMembers(groupId);

    // 3. 获取成员列表（用于后续调用）
    const members = await listMembers(groupId);
    console.log('成员任务已持久化保存:', members.map(m => ({
      name: m.appName,
      tasks: m.tasks
    })));

    // 4. 发起群聊对话（为每个成员依次调用）
    // AI会自动根据成员的任务调整回复内容
    await startGroupChat(groupId);

    console.log('✅ 群聊功能演示完成！');
    console.log('💡 任务信息已保存在对话组中，后续对话AI会自动参考');
  } catch (error) {
    console.error('❌ 错误:', error);
  }
}

// 执行
main();

Python 完整示例

import requests
import json

BASE_URL = 'http://your-domain:9520/api/open'
USER_ID = 1001

def request(endpoint, data):
    """发送 POST 请求"""
    url = f'{BASE_URL}{endpoint}'
    response = requests.post(url, json=data)
    return response.json()

def create_group():
    """创建对话组"""
    result = request('/group/create', {'userId': USER_ID})
    print('对话组已创建:', result['data'])
    return result['data']['id']

def add_members(group_id):
    """批量添加成员（同时分配任务）"""
    data = {
        'userId': USER_ID,
        'groupId': group_id,
        'members': [
            {
                'appId': 456,
                'order': 1,
                'role': 'leader',
                'taskDetail': '完成需求分析文档'
            },
            {
                'appId': 457,
                'order': 2,
                'role': 'member',
                'taskDetail': '设计系统架构'
            },
            {
                'appId': 458,
                'order': 3,
                'role': 'member',
                'taskDetail': '实现核心功能'
            }
        ]
    }
    result = request('/group/members/add', data)
    print(f"批量添加成员成功，共添加 {result['data']['count']} 个成员:", result)

def start_group_chat(group_id):
    """发起群聊"""
    # 先获取成员列表
    members = list_members(group_id)

    # 为每个成员依次调用接口
    for i, member in enumerate(members):
        data = {
            'userId': USER_ID,
            'prompt': '大家好，我们来讨论一下新功能的实现方案',
            'appId': member['appId'],  # 当前成员的 appId
            'options': {
                'groupId': group_id,
                'isFirstMember': i == 0     # 第一个成员为 True
            }
        }
        result = request('/chat/chat-process', data)
        print(f"成员 {member['appName']} 的回复:", result)

def list_members(group_id):
    """查看成员列表"""
    result = request('/group/members/list', {
        'userId': USER_ID,
        'groupId': group_id
    })
    print('成员列表:', result['data'])
    return result['data']

def main():
    """主流程"""
    try:
        # 1. 创建对话组
        group_id = create_group()

        # 2. 添加成员（同时分配任务）
        # 任务会持久化保存在对话组中，无需额外更新
        add_members(group_id)

        # 3. 获取成员列表
        members = list_members(group_id)
        print('成员任务已持久化保存:', [(m['appName'], m['tasks']) for m in members])

        # 4. 发起群聊对话（为每个成员依次调用）
        # AI会自动根据成员的任务调整回复内容
        start_group_chat(group_id)

        print('✅ 群聊功能演示完成！')
        print('💡 任务信息已保存在对话组中，后续对话AI会自动参考')
    except Exception as e:
        print(f'❌ 错误: {e}')

if __name__ == '__main__':
    main()

⭐ 最佳实践

✅ 成员管理

  • 统一 ID：memberId 使用与 appId 相同的值
  • 清晰命名：为成员设置有意义的 name（如"产品经理"）
  • 合理排序：使用 order 控制发言顺序（1、2、3...）
  • 角色区分：使用 role 标识成员职责（leader/member）

✅ 任务管理

  • 创建时设置：在添加成员时通过 taskDetail 参数设置任务
  • 明确目标：任务描述要清晰具体，AI会据此调整回复
  • 持久化保存：任务自动保存在对话组中，长期有效
  • 自动生效：AI会自动读取任务信息，影响对话内容

✅ 对话策略

  • 指定角色：通过 appId 明确当前发言角色
  • 保持上下文：始终使用同一个 groupId
  • 任务导向：提问时引导 AI 关注任务目标
  • 轮流发言：利用 order 实现有序对话

✅ 性能优化

  • 批量操作：一次添加所有成员后再开始对话
  • 缓存信息：客户端缓存 groupId 和成员列表
  • 异步处理：对话可能较长，建议异步处理
  • 错误重试：网络错误时自动重试

推荐的对话流程

  1. 初始化阶段：创建对话组 → 添加所有成员（设置任务） → 任务持久化保存
  2. 对话阶段：用户提问 → AI 按顺序回复（自动参考任务） → 记录关键信息
  3. 协作阶段：成员依次发言 → AI 根据任务调整内容 → 持续迭代
  4. 查看阶段：随时查看成员列表 → 确认任务信息 → 导出对话记录
💡 核心理念：任务在创建时设置好，AI自动参考，无需人工频繁更新。

常见错误避免

❌ 常见错误：
  • 忘记在对话时传递 options.groupId → 导致无法启用群聊模式
  • 忘记传递 isFirstMember 参数 → 导致用户消息重复保存
  • 所有成员都传 isFirstMember: true → 导致用户消息重复
  • 不同成员的 prompt 不一致 → 导致对话混乱
  • appId 不正确 → 导致角色匹配失败
  • 多次添加同一个成员 → 虽然不会报错但会导致数据混乱
  • 删除对话组后继续使用 → 会返回 404 错误
  • 不同用户的 userId 相同 → 会导致数据串扰
✅ 正确做法：
  • ✅ 第一个成员：isFirstMember: true，保存用户消息
  • ✅ 后续成员：isFirstMember: false，复用已保存的用户消息
  • ✅ 所有成员使用相同的 prompt
  • ✅ 先查询成员列表，再按 order 顺序调用

🤖 群聊自动对话 新功能

什么是自动对话？

自动对话功能允许 AI 角色基于历史对话自动生成回复，无需用户提供新的提示词。角色们可以根据之前的对话内容自动接力发言，实现真正的多角色自主协作。

典型场景：

  • 🎭 角色扮演：多个角色基于故事背景自动展开对话
  • 💡 头脑风暴：团队成员围绕话题自动提出观点
  • 📚 教学模拟：教师、学生自动进行知识讨论
  • 🎮 游戏NPC：多个NPC基于剧情自动对话
⚠️ 关键区别：
  • 普通群聊：用户提问 → 所有角色依次回复用户的问题
  • 自动对话：角色1发言 → 角色2基于角色1的内容发言 → 角色3基于前两者发言 → ...

如何实现自动对话

核心参数：skipPromptInHistory

在 options 中添加 skipPromptInHistory: true 参数，表示：

  • ✅ 不将当前 prompt 保存到对话历史
  • ✅ AI 完全基于群组的历史对话生成回复
  • ✅ 允许 prompt 为空字符串
参数类型必填说明
options.skipPromptInHistoryboolean✅设置为 true 启用自动对话模式
promptstring❌可以传空字符串 ""
options.isFirstMemberboolean✅自动对话模式下应设为 false

JavaScript 完整示例

// 群聊自动对话完整示例
const BASE_URL = 'http://your-domain:9520/api/open';
const USER_ID = 1001;
const GROUP_ID = 123;

// 获取成员列表
async function getMembers(groupId) {
  const res = await fetch(`${BASE_URL}/group/members/list`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ userId: USER_ID, groupId })
  });
  const data = await res.json();
  return data.data.sort((a, b) => a.order - b.order);
}

// 自动对话：让所有角色依次自动发言
async function autoChat(groupId, rounds = 1) {
  const members = await getMembers(groupId);

  for (let round = 0; round < rounds; round++) {
    console.log(`[第 ${round + 1} 轮自动对话]`);

    for (let i = 0; i < members.length; i++) {
      const member = members[i];

      const response = await fetch(`${BASE_URL}/chat/chat-process`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          userId: USER_ID,
          prompt: '',  // 空提示词
          appId: member.appId,
          options: {
            groupId: groupId,
            isFirstMember: false,  // 自动对话模式
            skipPromptInHistory: true  // 关键参数
          }
        })
      });

      // 处理流式响应
      const reader = response.body.getReader();
      const decoder = new TextDecoder();
      let fullText = '';

      while (true) {
        const { done, value } = await reader.read();
        if (done) break;

        const chunk = decoder.decode(value);
        const lines = chunk.split('\n').filter(line => line.trim());

        for (const line of lines) {
          try {
            const data = JSON.parse(line);
            if (data.content && data.content[0]?.text) {
              fullText = data.content[0].text;
              console.log(`[${member.appName}] ${fullText.substring(0, 50)}...`);
            }
          } catch (e) {}
        }
      }

      console.log(`[${member.appName}] 完成: ${fullText}`);

      // 等待1秒再继续下一个角色
      await new Promise(resolve => setTimeout(resolve, 1000));
    }
  }

  console.log('✅ 自动对话完成！');
}

// 使用示例：
// 先由用户发起话题（普通群聊）
// 然后调用 autoChat 让角色自动接力讨论
autoChat(GROUP_ID, 2);  // 自动对话2轮

🔧 故障排查

常见问题及解决方案

❓ 问题 1：创建对话组成功，但对话时没有启用群聊模式

原因：只创建了对话组，没有添加成员。

解决：使用 /api/open/group/members/add 至少添加一个成员，群聊模式会自动启用。

// 检查对话组的 isGroupChat 字段
{
  "isGroupChat": true  // ✅ 已启用
  "members": "[...]"   // ✅ 有成员数据
}

❓ 问题 2：对话时 AI 没有按照成员顺序回复

原因：成员的 order 设置不正确，或对话时没有传递 groupId。

解决：

  1. 确认成员的 order 设置正确（1、2、3...）
  2. 对话时确保传递了 options.groupId
  3. 检查 appId 是否与成员的 appId 匹配

❓ 问题 3：返回 "非法操作、您无权限访问该对话组"

原因：userId 不匹配，或 groupId 不存在。

解决：

  • 确认 userId 与创建对话组时使用的 userId 一致
  • 使用 /api/open/group/query 查询对话组列表，确认 groupId 存在

❓ 问题 4：任务分配成功，但 AI 回复时没有考虑任务

原因：任务的 title 或 detail 不够明确。

解决：设置清晰的任务标题和详情，AI 会根据任务内容调整回复重点。

// ❌ 不够明确
{
  "title": "工作"
}

// ✅ 清晰明确
{
  "title": "完成产品需求分析文档",
  "detail": "包含用户画像、功能列表、交互流程"
}

❓ 问题 5：成员列表中没有显示 appAvatar

原因：角色应用没有设置 coverImg，或 appId 不正确。

解决：

  • 确认添加成员时传递了正确的 appId
  • 检查角色应用是否设置了 coverImg 字段

❓ 问题 6：对话记录中出现多条相同的用户消息 常见

原因：没有正确使用 isFirstMember 参数，导致每个成员都保存了用户消息。

错误示例：

// ❌ 错误：每个成员都传 isFirstMember: true
成员1: { ..., "options": { "isFirstMember": true } }
成员2: { ..., "options": { "isFirstMember": true } }  // ❌ 应该为 false
成员3: { ..., "options": { "isFirstMember": true } }  // ❌ 应该为 false

// 结果：数据库中有3条用户消息，对话记录混乱
用户: 你好
用户: 你好  // 重复
用户: 你好  // 重复
成员1: 回复...
成员2: 回复...
成员3: 回复...

正确做法：

// ✅ 正确：只有第一个成员传 isFirstMember: true
成员1: { ..., "options": { "isFirstMember": true } }
成员2: { ..., "options": { "isFirstMember": false } }
成员3: { ..., "options": { "isFirstMember": false } }

// 结果：只有1条用户消息，对话记录正常
用户: 你好
成员1: 回复...
成员2: 回复...
成员3: 回复...

❓ 问题 7：群聊时提示"未找到已有用户消息"

原因：第一个成员的请求还未完成时，后续成员已经开始请求。

解决：

  • 确保按顺序调用（等待上一个成员的请求完成后再调用下一个）
  • 后端会自动等待500ms后重试，通常可以解决
  • 如果仍有问题，可以在客户端增加延迟（如200ms）
