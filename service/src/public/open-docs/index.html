角色创建（POST /api/open/app/createApp）

请求体字段

字段说明是否必填
nameApp 应用名称是
catId分类 ID 列表（逗号分隔）是
preset角色设定/预设场景信息推荐
coverImg封面图片 URL否
voiceId角色默认音色 ID（DashScope/CosyVoice voice_id）否
emotionVoices情绪-音色映射数组；元素仅传 { emotionId, voiceId } 且 voiceId 非空否

返回体

字段说明
code状态码，200 表示成功
message消息文本
data创建后的角色对象

data 对象字段

字段说明
id角色ID
nameApp 应用名称
catId分类 ID 列表（逗号分隔）
preset角色设定/预设场景信息
coverImg封面图片 URL
status状态：1 启用，0 禁用
order排序值（数字越大越靠前）
createdAt/updatedAt创建/更新时间

开放·聊天

聊天对话（POST /api/open/chat/chat-process）

字段说明必填
userId外部用户ID（系统内有效）是
prompt用户提问内容；传 audioUrl 时将自动进行 ASR 转文本否
audioUrl音频URL，自动进行 ASR（与 audioBase64 二选一）否
imageUrl图片URL否
fileUrl文件URL否
appId角色ID否
model / modelName / modelType / modelAvatar模型相关参数否
options / extraParam / usingPluginId附加选项/插件/扩展参数否

语音对话（POST /api/open/chat/chat-process-voice）

需传 userId，并提供 audioUrl 或 audioBase64 其一

TTS 文字转语音（POST /api/open/chat/tts-process）

字段说明必填
userId外部用户ID是
prompt要合成的文本是
chatId继续会话ID（可选）否

角色更新（POST /api/open/app/updateApp）

请求体字段

字段说明是否必填
id角色 ID是
nameApp 应用名称否
catId分类 ID 列表（逗号分隔）否
preset角色设定/预设场景信息否
coverImg封面图片 URL否
voiceId角色默认音色 ID否
emotionVoices情绪-音色映射数组；元素仅传 { emotionId, voiceId } 且 voiceId 非空否

返回体

字段说明
code状态码
message消息文本（如“修改角色信息成功”）
data无或变更后的信息
说明：当仅更新情绪音色映射而主表无字段变更时，也会返回成功。
